Consolidating GPUs for Local LLM Inference

THE PROBLEM

Running multiple large language models (LLMs) concurrently can drain GPU resources and introduce performance bottlenecks. If you’re trying to own your stack and consolidate GPU power on one machine for local LLM inference, you'll face challenges such as managing VRAM usage, handling cold starts, and optimizing semaphore configurations. This article guides you through consolidating GPUs and running multiple models smoothly.

THE STACK

Hardware: - 3090 or similar high-end NVIDIA GPU - Ryzen 9 5900X CPU (or equivalent) for robust performance - Sufficient RAM to support heavy computation tasks - SSD storage for fast data access

Software: - Windows operating system with WSL/Ubuntu compatibility - Python 3.8+ environment set up via venv or Anaconda - Ollama installed and configured - ImageMagick (for handling image operations) - nvidia-smi tool to monitor GPU usage

THE GOTCHAS

  • Semaphore Configuration: Running three agents in parallel can consume approximately 23GB of VRAM. Adjust the semaphore back to 2 if you observe VRAM pressure or model eviction warnings.

  • Warmup Process: The warmup process reduces cold start latency, ensuring that the first /crew command is handled with a hot model. This drops synthesis time from around 60 seconds to about 7 seconds.

  • Performance Degradation: Performance degradation can occur when running three agents in parallel due to shared GPU resources; each agent runs at approximately 60-70% of full speed compared to running alone.
