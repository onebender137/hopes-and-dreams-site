Sync Your Obsidian Vault Across Devices with Git: Own Your Stack

The problem is clear: you want to take control of your notes and sync them seamlessly across multiple devices without relying on centralized services. The solution? Set up Obsidian with a GitHub repository using the Git plugin, ensuring that both your desktop and mobile devices stay in sync.

THE PROBLEM

You’ve got notes scattered across different environments—your desktop at home and your phone while you’re out. To keep everything consistent and accessible, you need to set up Obsidian on both devices so they can sync via a GitHub repository. This ensures that no matter where you are or what device you're using, your notes stay current.

THE STACK

To achieve this setup, you'll need: - Obsidian: A powerful note-taking application. - GitHub Account: For hosting the repository. - Git Plugin for Obsidian (version 2.83.2): To manage version control within Obsidian. - Desktop Computer and Mobile Device (Android): Both devices should have Obsidian installed.

THE BUILD

Desktop Setup

  1. Install the Git plugin in Obsidian (ensure it's version 2.83.2).
  2. Configure auto-pull and auto-push intervals to every 5 minutes each. - In settings, change the auto-push interval from 0 to 5.

Mobile Setup (Android)

  1. Install Obsidian and ensure it has Git support.
  2. Create a GitHub Personal Access Token with repo access permissions.
  3. In the Obsidian settings, authenticate using your token and username (onebender137).
  4. Set the remote URL to https://github.com/onebender137/Obsidian.git.
  5. Clone the repository from GitHub into your Obsidian vault.

THE GOTCHAS

  • Ensure both devices have similar auto-interval settings for syncing. In this case, 5 minutes is set for both desktop and mobile.
  • Use the "Commit-and-sync and close" command manually to trigger syncs when needed on mobile.
  • Be mindful of potential issues with Obsidian’s Git plugin stability, especially on larger vaults or using isomorphic-git on mobile.

This setup ensures consistent syncing between your desktop and mobile devices via GitHub, allowing seamless note-taking across different environments. However, keep an eye out for any inconsistencies due to the manual nature of syncing commands on mobile and potential performance issues with larger repositories.
